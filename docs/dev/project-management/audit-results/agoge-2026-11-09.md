**Options.**

**Recommendation: A.** Against it: it changes the snapshot format, so the version bump must be coordinated with PRD 00009, which also bumps it.

**Options.**

- **B. Add `fsmonitor--daemon*` to `GITDIR_UNCHECKED` only.** Benefit: one line. Drawback: the daemon still starts. Effort S.

**Recommendation: A.** Against it: until both land, the bug stays.
